DAY 03 – Technology Selection

Date: 24/6/2026

Today was the third day of my minor project development. Under the guidance of my project mentor, I started researching and selecting the appropriate technologies and tools
required for developing Veltrix AI. My mentor explained that selecting the right technology stack is an important step because it directly affects the performance,
scalability, development process and overall functionality of the application.

During the discussion, my mentor guided me to compare different programming languages and frameworks that could be used for developing an AI-powered application. After 
considering factors such as ease of development, availability of libraries, API support and integration capabilities, I decided to use Python as the primary programming 
language.

For developing the user interface, we discussed different web application frameworks. I selected Streamlit because it provides a simple and efficient way to develop
interactive Python-based applications without requiring extensive frontend development.

For the artificial intelligence component, I selected Google Gemini. My mentor explained how large language models can understand natural-language instructions, process 
user queries and generate meaningful responses. We also discussed how Gemini could be integrated with the application through its API.

For database management, I selected MongoDB Atlas because it provides cloud-based database services and supports flexible document storage. This would help in storing user 
contacts, reminder details and other application information.

Additionally, I explored Twilio for handling automated outbound phone calls and ElevenLabs for converting text into natural-sounding speech. My mentor explained the
importance of using external APIs to integrate specialized services into the application rather than developing every feature from scratch.

After evaluating the technologies, I finalized the initial technology stack for Veltrix AI.

**Work Performed:**

- Researched different programming languages and development frameworks with the guidance of my mentor.
- Selected Python as the primary programming language due to its simplicity and extensive AI library support.
- Selected Streamlit for developing the interactive user interface.
- Selected Google Gemini as the AI model for natural-language understanding and response generation.
- Explored the Gemini API and its integration possibilities with Python.
- Selected MongoDB Atlas as the cloud-based database for storing contacts and reminder tasks.
- Researched Twilio and its capabilities for initiating automated outbound phone calls.
- Explored ElevenLabs for text-to-speech conversion and natural voice generation.
- Compared the selected technologies based on their features, compatibility and suitability for the project.
- Prepared the initial technology stack and discussed the next development steps with my mentor.

**Learning Outcome:**

Today, I learned how to evaluate and select suitable technologies for a software development project. I understood the importance of Python in AI-based application 
development, the advantages of Streamlit for creating interactive interfaces and the role of APIs in connecting external services. With my mentor's guidance, I finalized 
the initial technology stack for Veltrix AI, which provided a technical foundation for the implementation phase.
