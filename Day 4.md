### DAY 04 – Development Environment Setup

Date:25/6/2026

Today was the fourth day of my minor project development. After finalizing the technology stack, I started preparing the development environment for Veltrix AI. Under the
guidance of my project mentor, I learned about the importance of setting up a proper development environment before beginning the actual implementation of the application.

My mentor guided me through the installation and configuration of the required software tools. I started by checking the Python installation and configuring it on my system.
Since Python was selected as the primary programming language, I ensured that it was properly installed and accessible through the terminal.

Next, I installed Visual Studio Code as my primary code editor. My mentor explained how VS Code provides useful features such as syntax highlighting, debugging, terminal 
integration and extensions that make Python development easier.

After configuring the development tools, I created a separate project directory named Veltrix AI to maintain all the source code and related files in an organized manner. 
I also explored how a proper folder structure helps in managing different modules of a software application.

I then installed Streamlit and other basic Python dependencies required for the initial development. I learned how Python libraries can be installed using the pip package
manager and how dependencies are used to extend the functionality of an application.

Finally, I created a basic Streamlit application and executed it locally to verify that the development environment was working correctly. My mentor also guided me on 
resolving basic installation and configuration issues.

**Work Performed:**

- Prepared the development environment according to the finalized technology stack.
- Installed and configured Python for application development.
- Verified Python installation and checked its accessibility through the command prompt.
- Installed Visual Studio Code as the primary development editor.
- Explored useful VS Code features and Python extensions.
- Created the main project directory named Veltrix AI.
- Discussed the importance of maintaining an organized project folder structure.
- Installed Streamlit using the Python package manager.
- Installed the basic Python libraries required for initial development.
- Learned how to manage Python dependencies using pip.
- Created and executed a basic Streamlit application.
- Tested the local development environment and verified that the application could run successfully.

**Learning Outcome:**

Today, I learned how to prepare and configure a Python-based development environment. I gained practical knowledge of using Visual Studio Code, managing Python packages,

familiar with the tools required for the further development of Veltrix AI.
